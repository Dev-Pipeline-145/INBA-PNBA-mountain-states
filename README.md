# INBA/PNBA Mountain States Website

A professional, responsive web application for showcasing natural bodybuilding competitions across Utah, Colorado, and the Mountain States region.

## Quick Start

```bash
# Clone the repository
git clone https://github.com/Dev-Pipeline-145/INBA-PNBA-mountain-states.git

# Navigate to project directory
cd INBA-PNBA-mountain-states

# Open in browser
open index.html
```

## Project Structure

```
project-root/
├── src/
│   ├── components/
│   │   ├── layout/              # Header, Footer, Navigation
│   │   ├── forms/               # ContactForm, RegistrationForm
│   │   ├── ui/                  # Button, Card, etc.
│   │   └── pages/               # All page components
│   ├── styles/                  # All SCSS files
│   ├── utils/                   # Helper functions
│   └── assets/                  # Processed assets (CSS, JS)
├── public/                      # Static assets
│   ├── images/
│   ├── icons/
│   └── logos/
└── docs/                        # Documentation
    ├── README.md               # Detailed project documentation
    └── deployment.md           # Deployment guide
```

## Features

- **Dark Mode Design** - Cyberpunk aesthetic with cyan and purple accents
- **Responsive Layout** - Mobile-first design approach
- **Component-Based** - Reusable UI components
- **Modern CSS** - SCSS with BEM methodology
- **Interactive Elements** - Smooth animations and transitions

## Technologies

- **HTML5** - Semantic markup
- **SCSS** - CSS preprocessing
- **JavaScript** - Interactive functionality
- **BEM** - CSS naming convention
